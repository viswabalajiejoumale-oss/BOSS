================================================================================

1.1 PROJECT MISSION & CORE OBJECTIVE
--------------------------------------------------------------------------------
BOSS (Battery Optimized Software Service) is an enterprise-grade, end-to-end 
smart electric vehicle (EV) charging ecosystem designed to solve the two biggest 
bottlenecks facing the global EV transition:
1. EV Driver Range & Charging Anxiety (long queues, broken chargers, unpredictable power, and lack of real-time slot guarantees).
2. Distribution Grid & Transformer Overload (localized power surges and grid instability caused by uncoordinated high-power DC fast-charging).

BOSS seamlessly bridges three key stakeholders into a single unified platform:
- EV DRIVERS: Live station discovery, Explainable AI recommendations, 1-hour guaranteed pre-booking, camera-based SOC verification, real-time charging telemetry, and SOS mobile rescue truck dispatch.
- STATION OPERATORS (ADMINS): Physical Smart Meter 6-digit OTP verification terminal, real-time port load controls, transformer safety limits (kVA), and queue monitoring.
- ELECTRICAL UTILITIES (DISCOMs): City-wide feeder telemetry, automated peak load shaving, transformer stress alerts, and dynamic off-peak tariff incentive distribution.

3.4 BACKEND, DATABASE & AUTHENTICATION
--------------------------------------------------------------------------------
• SUPABASE CLOUD POSTGRESQL (@supabase/supabase-js 2.111.0):
  - Role: Cloud backend database, user authentication, and real-time state synchronization.
  - Tables:
      * `profiles`: User accounts, vehicle mappings, role designations (`user`, `admin`, `discom`).
      * `stations`: Geographical coordinates, operator network, transformer capacity (kVA), current load (kVA).
      * `chargers`: Port IDs, connector types, maximum power (kW), live status (`available`, `occupied`, `fault`).
      * `reservations`: 1-hour slot records, 6-digit OTP codes, output DC voltage, battery SOC, session status.
      * `notifications`: Real-time grid alerts, overload warnings, and reservation updates.
  - Row Level Security (RLS): Strict policies ensuring drivers can only access their own reservations, admins manage their assigned station, and DISCOM operators inspect aggregate telemetry.

• REALTIME WEBSOCKET SUBSCRIPTIONS & HYBRID FALLBACK:
  - Role: Pushes instant database updates when a port is booked or transformer load changes.
  - Hybrid Fallback Engine (`src/lib/backendServices.ts`): If cloud network connectivity drops, the system seamlessly falls back to an in-memory / LocalStorage cache to ensure zero service disruption.


3.5 ARTIFICIAL INTELLIGENCE & MACHINE LEARNING
--------------------------------------------------------------------------------
• MACHINE LEARNING LINEAR REGRESSORS (`src/lib/aiEngine.ts`, `src/data/mlChargingModel.json`):
  - Trained in Python (`train_and_sync.py`) using scikit-learn on historical EV charging session datasets.
  - Predicts machine output DC voltage and active power draw based on vehicle battery state and charging current.

  - Uses browser HTML5 Canvas image processing (grayscale transformation, Otsu binarization, digit segment bounding) to extract numerical SOC % from vehicle dashboard camera snapshots.

  - Connects to OpenRouter API to route prompts to top LLMs (Google Gemini 2.5 Flash, DeepSeek R1, Meta Llama 3.3).
  - Injects live telemetry state into system prompts to deliver accurate, contextual EV and grid insights.

4. SUMMARY OF KEY ALGORITHMS & MATHEMATICAL FORMULAS
================================================================================

1. HAVERSINE GEOSPATIAL DISTANCE:
   a = sin²(Δlat/2) + cos(lat1) * cos(lat2) * sin²(Δlon/2)
   Distance (km) = 2 * R * atan2(√a, √(1-a))  [where R = 6371 km]

2. STATION TRANSFORMER UTILIZATION %:
   Load % = (Active Power Draw in kW / Transformer Capacity in kVA) * 100
   * Trigger Condition: If Load % >= 80%, lock new bookings and initiate Smart Redirection.

3. EXPLAINABLE AI MATCH SCORE:
   Score = 100 - [ (w1 * Distance_km) + (w2 * Wait_Time_min) + (w3 * (Price - BasePrice)) + (w4 * (Load_% / 10)) ]

4. ML DC OUTPUT VOLTAGE & POWER FORMULATION:
   V_DC (Volts) = V_nominal + (SOC% * 0.82) + (Current_Amps * 0.048)
   Active Power (kW) = (V_DC * Current_Amps) / 1000

5. VOLTOPTIMIZE GREEN REWARD & CARBON OFFSET:
   CO2 Saved (kg) = kWh_Charged * 0.82 (Grid Carbon Factor) * Renewable_Mix_Ratio
   VoltCredits Earned = kWh_Charged * (1 + (100 - Station_Load_%) / 100)
